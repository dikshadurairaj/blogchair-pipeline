# Header Mapping Rules

Follow these rules when writing the header of a blog Markdown file.

1. The author name is spelled and capitalized exactly as it appears in the Google Form row.
2. The event title is spelled and capitalized exactly as it appears in the Google Form row.
3. Both go into the Markdown header, following the repo's header structure (a line in the Google Form defines the header).
4. If the spelling in the form and the spelling in the event title differ, the form wins — never "correct" or restyle it.
