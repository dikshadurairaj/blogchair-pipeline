# Title Carry-Through Rules

Follow these rules when drafting the Slack message to the Web Committee Director.

1. The message contains the event title from the form submission.
2. The message contains "@Web Committee Director".
3. It is a draft only — the Blog Chair sends it. Do not post it yourself.
4. No GitHub link is included in version 1.
