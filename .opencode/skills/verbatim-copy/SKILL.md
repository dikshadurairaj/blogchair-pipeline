# Verbatim Copy Rules

Follow these rules when copying the body of a blog post into Markdown.

1. Count the paragraphs in the raw submission text first.
2. The Markdown file must have the exact same number of paragraphs as the original.
3. Leave the paragraph text exactly as written — same words, same spelling, same capitalization.
4. Do not reword, trim, add, or "clean up" the body. Verbatim copy only.
